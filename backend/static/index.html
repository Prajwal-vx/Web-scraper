Security Architecture & Ethical Crawling Policy

NEXUS SCRAPE AI is engineered strictly for authorized, polite data intelligence.

SSRF Defense Enforcement

All outbound requests validate destination DNS resolutions against private IPv4/IPv6 networks, loopback addresses, and cloud instance metadata (AWS 169.254.169.254, GCP metadata.google.internal). Redirects are individually re-evaluated to thwart DNS rebinding.

Strict robots.txt Compliance

The engine inspects target robots.txt and honors User-Agent rules and Crawl-delay directives. Sites or paths flagged as disallowed are automatically skipped without overriding access controls.
